# AWS Certified Solutions Architect – Associate (SAA-C03) Study Guide & Resource Kit

Welcome to the ultimate community-driven study repository for the **AWS Certified Solutions Architect – Associate (SAA-C03)** exam.

The SAA-C03 certification validates your ability to design secure, resilient, high-performing, and cost-optimized architectures on Amazon Web Services using the AWS Well-Architected Framework. Rather than basic definitions, the exam focuses on evaluating trade-offs (e.g., latency vs. cost, managed vs. self-managed, synchronous vs. decoupled messaging) across cloud infrastructure designs.

This repository provides architectural patterns, decision matrix tables, practical CLI/IaC snippets, a 30-day preparation schedule, and guidelines for obtaining exam registration vouchers.

## Exam Overview

| Aspect | Details |
| :--- | :--- |
| **Exam Code** | SAA-C03 |
| **Registration Fee** | $150 USD (plus applicable local taxes) |
| **Duration** | 130 Minutes |
| **Number of Questions** | 65 (50 scored, 15 unscored items) |
| **Passing Score** | 720 / 1000 (Scaled Scoring Model) |
| **Question Types** | Multiple Choice (1 answer) & Multiple Response (2+ answers) |
| **Delivery Options** | Pearson VUE online proctored or in-person testing centers |
| **Validity** | 3 Years |

## Who Should Take This Exam?

This certification is designed for:
- **Cloud Engineers & Architects** seeking formal validation of their AWS architectural capabilities.
- **SysAdmins & DevOps Professionals** transitioning from traditional infrastructure to cloud-native or hybrid systems.
- **Developers** looking to deepen their understanding of enterprise networking, security, and multi-tier system designs.
